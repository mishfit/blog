This site uses Nokware's self-hosted analytics to understand which articles people visit, which platforms refer readers, and which invitations lead to confirmed email subscriptions. It does not use Facebook pixels or Google Analytics.

A random visit identifier and referral context are held in browser session storage for a rolling 30-minute visit. Analytics receives page paths and approved campaign fields, rather than arbitrary query strings, email addresses or form contents. The web server receives an IP address for the connection, but analytics uses a neutral address and the opaque visit identifier instead of your address as a visitor key. Analytics records are kept for up to 13 months, with backups retained for 30 days.

Do Not Track and Global Privacy Control disable collection. Draft previews do not collect visits. Visitor totals remain estimates and can miss blocked requests.

Email subscriptions require a separate confirmation. Mail management retains email addresses and consent records with the original referring page or campaign when available. Confirmation tokens and email addresses are not exported to visitor analytics. Links in campaign emails can record which recipient link was requested. Security scanners can request those links too, so a recorded request does not establish that a person read an email. You can unsubscribe from marketing emails at any time.
