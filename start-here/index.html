I am Mish. I write, build software, run experiments, and occasionally make the internet look more organized than it has any right to be.

This site is the home base for the work that does not fit cleanly inside a client repo, a social profile, or a private notebook.

What this is about

The current thread running through my work is simple:

  • build useful software in public
  • learn how attention turns into owned relationships
  • test ideas with real projects instead of only opinions
  • keep notes that are honest enough to be useful later

The main experiments right now are creator tools, email systems, Nokmetia, and small software businesses under the Nokware umbrella.
